# Лабораторная работа № 2. Паттерн MVC

**Вариант 5 — магазин алкогольной продукции.**

«Винная полка» — учебный интернет-магазин на Django. Покупатель может добавить несколько экземпляров одного товара, уменьшить количество и увидеть общее число товаров и сумму. После регистрации или входа можно оформить заказ и посмотреть свои покупки.

## Запуск

Нужен Python 3.10 или новее. Команды для PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py loaddata products
.\.venv\Scripts\python.exe manage.py runserver
```

Открыть [http://127.0.0.1:8000/](http://127.0.0.1:8000/). На Linux и macOS используется `.venv/bin/python`.

## Структура приложения

- **Модель:** `shop/models.py` — товары, заказы и их позиции; база SQLite.
- **Контроллер:** `config/urls.py` и `shop/views.py` — маршруты и обработчики запросов.
- **Представление:** `shop/templates/` — шаблоны каталога, корзины, истории покупок и форм аккаунта.

Корзина хранится в сессии. При оформлении заказ и его позиции записываются одной транзакцией. Цена и название товара сохраняются в позиции заказа, поэтому история не зависит от последующих изменений каталога.

Учебный пример: [PTLab2](https://github.com/kpdvstu/PTLab2). Дополнительное задание по MVC: [методические материалы](https://github.com/citrux-at-vstu/programming-technologies-2).

## Вывод

На примере магазина разделены хранение данных, обработка запросов и построение страниц. Сессия позволяет менять корзину до входа, а авторизация связывает оформленный заказ с конкретным покупателем.
